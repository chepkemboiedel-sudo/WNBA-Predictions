Under the hood

How it was built

Every form feature uses only games played before the game it describes, and validation splits by time — train on the past, test on the future — so the model never peeks ahead.

Reading it fairly

What the model can't see

  • It knows only scores. No rosters, injuries, minutes, or trades — the Golden State and New York gaps are where that blind spot shows.
  • Playoff rest is neutralized. The sim doesn't model a team resting after a sweep or grinding through a decisive Game 3.
  • Seeding tiebreakers are simplified (win% then point differential), not the league's full head-to-head chain before the playoffs. Once available, actual first-round pairings resolve tied seeds.
  • Completed results are fixed. Only unplayed playoff games are simulated. Finals: Golden State Valkyries leads Atlanta Dream 3–2.
